End-to-End System Architecture

How the Information Retrieval vectorizer, Difficulty Classifier, and Domain NLP model interact:

01

Raw Metadata Ingestion

Dataset with 5,839 GitHub repositories. Cleans text, computes string lengths, validates numerical signals.

02

TF-IDF Search Index

Lemmatized word tokenization with stopwords removal. Computes sparse TF-IDF matrix for instant cosine similarity search.

03

Difficulty Classifier

Scales 7 numeric & length features via StandardScaler. Predicts Beginner (0), Intermediate (1), or Advanced (2).

04

NLP Domain Model

Tokenizes repo name, description, and readme preview. Assigns technical domain categories (Web, ML, Cyber, Games, General).
